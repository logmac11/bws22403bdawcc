📝 Step 2: Write GitHub Actions Workflow

Workflows are YAML files in .github/workflows/ that define triggers, jobs, and steps.

mkdir -p .github/workflows cat > .github/workflows/data-pipeline.yml << 'EOF' name: CampusMart Data Pipeline on: push: branches: [ main ] pull_request: branches: [ main ] workflow_dispatch: jobs: lint-and-test: runs-on: ubuntu-latest steps: - name: Checkout code uses: actions/checkout@v4 - name: Setup Python uses: actions/setup-python@v4 with: python-version: '3.10' - name: Install dependencies run: | python -m pip install --upgrade pip pip install pandas flake8 pytest - name: Lint with flake8 run: flake8 scripts/ --count --show-source --statistics - name: Run tests run: pytest tests/ -v simulate-deploy: needs: lint-and-test runs-on: ubuntu-latest if: github.ref == 'refs/heads/main' steps: - name: Checkout uses: actions/checkout@v4 - name: Simulate Deployment run: | echo "🚀 Deploying to production environment..." echo "✅ Pipeline executed successfully" EOF
🔍 YAML Breakdown:
  • on: Triggers (push, PR, manual dispatch)
  • jobs: Parallel or sequential execution units
  • needs: Dependency chain (test must pass before deploy)
  • if: Conditional execution (only on main branch)
  • uses: Reusable actions from GitHub Marketplace

🔑 Step 4: Secrets & Security Management

Never hardcode credentials. Use GitHub Secrets for sensitive data like API keys or database URIs.

1Add Repository Secret

Repo Settings → Secrets and variables → Actions → New repository secret → Name: MONGODB_URI → Value: mongodb://student:uthm2026@localhost:27017

2Update Workflow to Use Secret
# Add this step to the simulate-deploy job: - name: Use Secret run: | echo "🔐 Connecting to database securely..." # Masked in logs automatically echo "Connection string: ${{ secrets.MONGODB_URI }}" env: DB_URI: ${{ secrets.MONGODB_URI }}
⚠️
Security Rule: Secrets are encrypted at rest & masked in logs. Never print secrets in plain text or commit .env files.

🛠️ Troubleshooting & Tips

❌ "Workflow not triggering"

Verify file path: .github/workflows/ (exact spelling, lowercase). Check YAML indentation. Push to main branch or create PR.

❌ "Secrets not found" error

Secrets are scoped to the repository. Ensure you added it under Repo Settings → Secrets, not Organization. Forked repos don't inherit secrets.

❌ "pytest not found"

Ensure pip install pytest runs before the test step. Check Python version compatibility (3.8+ recommended).

💡 How to re-run failed jobs?

Actions UI → Click failed workflow → "Re-run jobs" → Choose "Re-run failed jobs" or "Re-run all jobs". Saves time vs full pipeline.
