🐳 Step 1: Install Docker Desktop

Docker lets us run MongoDB in isolated containers that work identically on every laptop.

1 Download Docker Desktop
Go to: https://www.docker.com/products/docker-desktop/
Click "Download for Windows" (free for students/education)
2 Run the Installer
- Double-click Docker Desktop Installer.exe
- ✅ Check "Use WSL 2 instead of Hyper-V"
- Click OK → Wait for installation to complete
3 Restart Your Computer
The installer will prompt you to restart. Do not skip this step.
4 Accept Subscription Agreement
After restart, open Docker Desktop. You'll see a subscription agreement popup.
As a UTHM student, you qualify for FREE personal/educational use.
Click "Accept" → Docker will load.
5 Wait for "Engine running"
Docker Desktop will show a green dot with "Engine running" at the bottom.
docker --version docker run hello-world

🔧 Step 2: Fix WSL (Windows Subsystem for Linux)

ℹ️
Note: This step is ONLY for Windows users who see the WSL update message in Docker. Skip if Docker started without errors.
1 Open PowerShell as Administrator
Press Windows Key → Type powershell → Right-click → "Run as administrator"
2 Update WSL
wsl --update

Wait 2-5 minutes for the update to download and install.

3 Shutdown WSL
wsl --shutdown
4 Complete WSL Setup (if prompted)
If you see "Create a default Unix user account:":
- Type a username (e.g., your name or "student") → Press Enter
- Type a password (nothing shows as you type — this is normal) → Press Enter
- Retype password → Press Enter
5 Return to Docker Desktop
Click the blue "Try Again" button. Docker should now start successfully.

🐚 Step 3: Install MongoDB Shell (mongosh)

The MongoDB Shell is the command-line interface for interacting with MongoDB databases.

🚨
IMPORTANT: mongosh is now a separate download from the database tools. You must install it separately.
1 Download MongoDB Shell
Go to: https://www.mongodb.com/try/download/shell
- Version: Latest stable
- Platform: Windows
- Package: MSI
- Click "Download"
2 Run the Installer
- Double-click the downloaded .msi file
- Choose "Complete" installation
- Click Next → Install → Finish
3 Restart PowerShell
Close ALL PowerShell/CMD windows. Open a NEW PowerShell window.
4 Verify Installation
mongosh --version

You should see a version number like 2.8.2. ✅

🛠️ Step 4: Install MongoDB Database Tools

These tools include mongoimport and mongoexport for loading and saving data.

1 Download Database Tools
Go to: https://www.mongodb.com/try/download/database-tools
- Version: Latest (100.x.x)
- Platform: Windows x86_64
- Package: MSI
- Click "Download"
2 Run the Installer
- Double-click the downloaded .msi file
- Choose "Complete" installation
- Click Next → Install → Finish
3 Restart Computer
⚠️ Critical: Restart your computer so Windows recognizes the new tools.
4 Verify Installation
Open a NEW PowerShell window and run:
mongoimport --version mongoexport --version

You should see version numbers like 100.16.0. ✅

⚠️
Still getting "not recognized" errors?
1. Press Windows Key → Type "env" → "Edit the system environment variables"
2. Click "Environment Variables" → Under "User variables", select Path → Edit
3. Click "New" → Add: C:\Program Files\MongoDB\Tools\100\bin
4. Click OK on all windows → Close ALL terminals → Open a NEW PowerShell

🖥️ Step 5: Install MongoDB Compass (GUI)

Compass is a free visual tool to explore MongoDB data without writing commands.

1 Download Compass
Go to: https://www.mongodb.com/products/compass
Click "Download MongoDB Compass" (free version)
2 Run the Installer
- Double-click the downloaded installer
- Follow the prompts → Install → Finish
3 Test Connection
1. Open MongoDB Compass
2. In the connection field, paste:
mongodb://localhost:27017/
4 Click "Connect". You should see "Connected to localhost".
(No databases will appear yet — that's normal! MongoDB server starts in Lab 1.)

🛠️ Troubleshooting Guide

Common issues and their solutions:

❌ "Port 27017 already in use"

Another MongoDB instance is running locally.

# Stop local MongoDB: net stop MongoDB # Or quit MongoDB from system tray
❌ "docker: command not found"

Docker is not installed or not in your PATH.

Fix:

  1. Install Docker Desktop from docker.com
  2. Restart your computer
  3. Open a NEW PowerShell window
  4. Verify: docker --version
❌ "mongosh: command not found"

MongoDB Shell is not installed or not in PATH.

Fix:

  1. Download from: mongodb.com/try/download/shell
  2. Install the MSI with "Complete" option
  3. Restart computer
  4. If still not found, add to PATH manually:
    C:\Program Files\MongoDB\Server\7.0\bin
❌ Docker shows "WSL needs updating"

See Step 2: Fix WSL above. Run wsl --update in PowerShell (Admin).

❌ Atlas asks for credit card

You selected the wrong tier. Go back and:

  1. Choose "Learn MongoDB / Personal Project"
  2. Select "M0 Sandbox (FREE)"
  3. Look for "Skip payment" or "Continue with free tier"
❌ Compass crashes on startup

Try these fixes:

  1. Update graphics drivers
  2. Run Compass as Administrator
  3. Use mongosh CLI instead (still 100% functional)
